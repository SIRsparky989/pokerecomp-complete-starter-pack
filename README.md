# Starter Pack for PokéRecomp

Starter Pack is a PokéRecomp mod for Pokémon Crystal that adds story-driven events for obtaining all six Generation 1 and Generation 2 starter Pokémon during a single adventure.

Rather than simply adding the starters to a menu or handing them directly to the player, each Pokémon has its own NPC, location, dialogue and progression requirements designed to feel like a natural part of Pokémon Crystal.

## Features

### Generation 2 Starters

The two Johto starters you did not originally choose can be obtained through new events as you progress through Johto.

- Chikorita — National Park
- Cyndaquil — Ecruteak City
- Totodile — Cianwood City

The mod remembers which Pokémon you originally received from Professor Elm. Your original starter is never duplicated by its corresponding event.

The Johto events become available naturally as you progress through the Gym challenge.

### Generation 1 Starters

All three original Kanto starters can also be obtained through new events inspired by Pokémon Yellow.

- Bulbasaur — Cerulean City
- Charmander — Route 25
- Squirtle — Vermilion City

These events reimagine and continue the stories behind their Pokémon Yellow counterparts several years later, fitting them into the world of Pokémon Crystal.

Bulbasaur's event also takes the happiness of your current party into account.

### Story-Driven Events

Starter Pack is designed to make the additional starters feel earned rather than simply given away.

NPCs react to your progress through the game, remember previous conversations and use native-style dialogue and Yes/No prompts.

Some NPCs also move naturally around the overworld instead of remaining completely static.

Pokémon received from these events use PokéRecomp's normal Pokémon gift system. If your party is full, the Pokémon can be sent to your current PC Box.

Newly obtained species are registered normally in the Pokédex.

### In-Game Settings

Starter Pack can be configured from:

`Mods → Community Mods → SIRsparky Mods → Starter Pack`

Two options are available:

- **MOD — ON/OFF**  
  Master switch for Starter Pack. Turning this OFF disables the mod's world actors, movement, interactions and event requests without deleting saved event progress.

- **ACTIVE — ON/OFF**  
  Controls the starter events while keeping the Starter Pack NPCs in the world. When ACTIVE is OFF, the NPCs remain visible and use normal location-based dialogue instead of offering starter events or gifts.

Changing either option does not reset your existing Starter Pack event progress.

### Original Starter Support

The mod uses PokéRecomp's original-starter tracking.

This means the mod remembers which Johto starter Professor Elm originally gave you even if that Pokémon has since:

- Evolved
- Been traded
- Been deposited
- Been released
- Left your current party

This prevents the corresponding starter event from giving you a duplicate of your original choice.

### Persistent Events

Event progress is stored separately for each save file.

The mod remembers important event states such as previous conversations and Pokémon that have already been received.

Saving and continuing your game will therefore preserve your Starter Pack progress.

## Supported Games

- Pokémon Crystal

Current development and testing has been performed on Pokémon Crystal.

Pokémon Gold and Silver are not currently supported by this release.

## Requirements

- PokéRecomp with Generation 2 mod support
- Gen 2 Mod API version 59 or newer

## Installation

1. Download the latest Starter Pack ZIP from the GitHub Releases page.
2. Install the ZIP using PokéRecomp's normal mod installation method.
3. Do not use GitHub's automatically generated **Source code** ZIP as the installable mod package.

## Current Version
